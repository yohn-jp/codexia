旧書庫の司書補である佐伯律は、頁の端に爪を立て、七年前の自分が引いた鉛筆の傍線をなぞった。

佐伯は右手の古傷を袖口で隠しながら、硝子戸の向こうに積もる灰を見つめた。

02 / HOW IT WORKS

複雑な物語を、
複雑なまま扱える。

書く、調べる、判断する。そのどれかのために別のツールへ移るのではなく、作品の文脈を保ったまま仕事を切り替えます。

01 / WRITE

原稿に、集中する。

静かな執筆面、作品の構成、Revisionと下書き保護。執筆を止めないための基盤。

執筆設計を見る ↗
02 / CONNECT

記述と、根拠を結ぶ。

人物や舞台、設定を、原稿中の言葉と結びつける。必要な情報へ迷わず戻る。

Knowledge設計 ↗
03 / DECIDE

提案の先は、作者が決める。

差分を確認して、採用か保持かを選ぶ。AIの提案と作品の確定を分ける。
