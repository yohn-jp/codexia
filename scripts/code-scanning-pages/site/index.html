データの範囲

現在の main に対する全状態のアラートを取得します。CodeQL 以外のツールも GitHub Code scanning に登録されていれば対象です。

JSON は GitHub API のアラート全項目、CSV はルール・重大度・ファイル位置・状態などを出力します。秘密情報を含む可能性があるため、ダウンロードしたファイルの共有範囲に注意してください。

この画面ではアラートを公開サーバーへ転送しません。取得結果はタブを閉じるか再読み込みすると消去されます。GitHub Actions の SARIF 原本そのものではありません。
