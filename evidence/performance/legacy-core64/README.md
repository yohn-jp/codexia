# Historical Core64 measurement evidence

The original tracked build and memory results are retained here byte-for-byte, including failed runs, manifests and logs. The former repository-relative paths were `results/core64-build/` and `results/core64-memory/`; locators within these records describe the original source/run and are not rewritten. These measurements were produced against predecessor Scriptorium/Git-era implementations and are not evidence of current PostgreSQL-backed runtime performance.

New measurement output belongs outside the checkout or in ignored `artifacts/`. Use the [current performance measurement contract](../../../docs/performance/README.md) for new measurements.
